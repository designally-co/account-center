## Context

The app's stack is not decided yet. The database part is needed first, because every other app will call its checks.

## Decision

Schema `account` is written as plain SQL files in `supabase/migrations/`, the same way as the brain's schema, and applied to Project Friday through the Supabase connector after a rehearsal that undoes itself. The app, when it is built, does not create or change these tables itself.

## Why

AI's choice in the build session, not discussed with Buk: the schema reads `auth` and HR, uses security definer functions, row level security and permissions for other apps' users, and must be checked by P Aek before it runs. One readable SQL file is easier to review and to rehearse than code generated by an app's migration tool.
